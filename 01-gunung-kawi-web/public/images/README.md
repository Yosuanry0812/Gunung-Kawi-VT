# Foto Asli Gunung Kawi

Masukkan foto dokumentasi proyek pada subfolder `home`, `history`, `location`, `information`, dan `virtual-tour`. Lihat `../../../03-dokumen/panduan-aset.md` untuk nama file dan cara mengaktifkannya di manifest.

Folder `reference/` berisi empat foto asli Gunung Kawi berlisensi terbuka yang dipakai sementara atas pilihan pengguna. `reference/attribution.json` memuat sumber, pencipta, lisensi, dan perubahan optimasi. Foto tersebut bukan dokumentasi proyek atau panorama 360°. Kredit sumber ditampilkan pada halaman Informasi.
